# Mob Scores

Mob Scores adds configurable entity-kill scoring to the required `ScoreKeeper`
plugin. It targets Paper 26.2 and 26.3, records the latest qualifying player
damager, and awards the configured value when the entity dies if that player
is online.

## Details

- Platform: Paper 26.2 and 26.3 only
- Language: Java
- Required dependency: ScoreKeeper 0.2.2 or newer
- Configuration: `plugins/MobScores/config.yml`
- Mob Scores commands and permissions: None
- Score storage: the ScoreKeeper `mob-scores` bucket
